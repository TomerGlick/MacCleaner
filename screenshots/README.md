# Screenshots

This directory contains screenshots for the Mac Storage Cleanup application.

## Current Screenshots

- `main-window.png` - Main storage analysis window
- `cleanup-candidates.png` - Cleanup candidates view
- `cleanup-progress.png` - Cleanup in progress
- `menu-bar-stats.png` - **NEEDED**: Menu bar system monitor popover

## How to Add Menu Bar Screenshot

To capture the menu bar stats screenshot:

1. Run the Mac Storage Cleanup app
2. Click the menu bar icon (hard drive icon in the menu bar)
3. The popover will show system stats
4. Take a screenshot using:
   - Press `Cmd + Shift + 4`
   - Press `Space` to capture the window
   - Click on the popover window
5. Save the screenshot as `menu-bar-stats.png` in this directory

## Screenshot Guidelines

- Use macOS native screenshot tool for consistency
- Capture at 2x resolution (Retina)
- Include some context (menu bar visible)
- Use light mode for consistency with other screenshots
- Ensure no personal information is visible
